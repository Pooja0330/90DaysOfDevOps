You will create a small text file and practice:

Creating a file
Writing text to a file
Appending new lines
Reading the file back

1. creating a dir.
cmd: mkdir day-06

2.creating a file.
touch day-06.txt

3.writing text to a file.
cmd: vim day-06.txt
then press i(to start writing),
press esc when done, the write :wq to save and exit.

4.Appending new lines.
cmd: echo"This is a new line" >>file name
    echo"This is a new line" >>day-06.txt

 5. reading the file back
 cmd: cat day-06.txt
